# 🚑 Saglik Rotam – AI-Powered Health Assistant  
### **Nuxt 3 + Firebase Auth + ChatGPT + TailwindCSS + Nuxt UI**


## 🩺 What Is Saglik Rotam?

**Saglik Rotam** is an intelligent digital health assistant designed to help users better understand their symptoms and make informed decisions about their next steps. By utilizing the **Infermedica medical decision-support API**, the system analyzes user-reported symptoms, evaluates possible conditions, identifies which medical specialist the user should consult, and determines the urgency level of the situation.

After receiving this preliminary assessment, users can continue in the **ChatGPT-powered discussion section**, where they can ask follow-up questions, clarify their concerns, or explore the assessment in more detail. Saglik Rotam does not replace professional medical evaluation; rather, it provides users with a clearer, more informed starting point and guides them toward the right specialist at the right time.

Saglik Rotam is an AI-supported health assistant web application built with Nuxt 3.  
It provides secure user authentication, an interactive ChatGPT-powered assistant, clean UI components, and Firebase deployment support.
