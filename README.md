# 🚑 Saglik Rotam – AI-Powered Health Assistant  
### **Nuxt 3 + Firebase Auth + ChatGPT + TailwindCSS + Nuxt UI**

Saglik Rotam is an AI-supported health assistant web application built with Nuxt 3.  
It provides secure user authentication, an interactive ChatGPT-powered assistant, clean UI components, and Firebase deployment support.

---

## 🚀 Features

### 🔐 Authentication
- Email & Password Sign Up / Login  
- Google Login  
- Facebook Login  
- Firebase Authentication SDK

### 💬 AI Chatbot
- ChatGPT-powered conversation system  
- Full chat history inside session  
- Uses `nuxt-chatgpt` module  
- Clean UI with UCard + UTextarea

### 🎨 User Interface
- Nuxt UI component library  
- TailwindCSS styling  
- Responsive layout  
- Light/Dark theme toggle  

### 🧭 Included Pages
- `/` → Home  
- `/login` → Login  
- `/signup` → Register  
- `/chatbot` → ChatGPT-based AI assistant  
- `/help` → Report Issue  
- Reusable Header navigation  

### ☁️ Deployment
- Firebase Hosting  
- Firebase Functions (Node 20 / Gen 2 via Nitro)  

---

| Technology | Purpose |
